# Setup

To start demonstrating augmented reality (displaying a model on a registration pattern) using this software, you need to
do the following:

1. Start a simple `http` server:
   ```shell
   http-server . --no-cache
   ```

   ```shell
   python3 -m http.server 8080
   ```
2. Register on [ngrok](https://ngrok.com/) and place this application.
   online on a temporary domain, redirecting it to your main service, i.e. `http` server.
   Example cmd to start `ngrok` service:
   ```shell
   ngrok http http://localhost:8080
   ```
3. Go from your smartphone to the temporary address generated by ngrok.
4. Point the camera at the image of the registration pattern.
